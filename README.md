# ML-Algorithm-IWU

## Learning Reflection

Through this assignment, I gained a better understanding of how different machine learning algorithms are used to solve real-world problems. I learned that supervised learning uses labeled data to make predictions, while unsupervised learning identifies patterns and groups within data. I also explored how algorithms are applied across tabular data, computer vision, and natural language processing.

One area I found especially interesting was Generative AI. Models such as GPT and diffusion models can create new content, including text and images, based on patterns learned during training. This helped me understand how AI has evolved beyond analyzing information to generating new content.

Creating this framework also showed me that choosing the right algorithm depends on the type of data, the problem being solved, and the expected outcome. I believe this knowledge will help me make better decisions when working on data analytics and AI-related projects in the future.
